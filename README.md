# Local Service Radio: landing

Static "on air soon" page. No build step on Vercel: it serves the files as they are.

The page follows the Local Service identity by Raphael Wicki (mini brand guide V1, October 2026). `index.html`, the icons, `og.png` and `fonts/` are generated by `brand-identity/tools/make_web_assets.py` in the project folder, from Raphael's files. To change the page, edit `brand-identity/tools/index.template.html` and run the script again; don't edit `index.html` by hand.

## Local preview

```
python3 -m http.server 8787
```

Then open http://127.0.0.1:8787. The font doesn't load when `index.html` is opened as a file.

## Deploy

Vercel deploys `main` with the default settings and serves `index.html`. `vercel.json` only adds response headers.
